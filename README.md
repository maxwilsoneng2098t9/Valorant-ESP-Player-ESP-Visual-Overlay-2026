# 🎯 Valorant ESP

**Player ESP & Visual Overlay — 2026**

High-performance Valorant ESP focused on clear player visuals and information display.  
Clean modular structure, fully configurable and easy to use.

---

## 🎯 What it is

**Valorant ESP** is a lightweight overlay tool that provides player boxes, names, health bars, distance and skeleton.  
It is designed to be stable, easy to configure and work with the latest Valorant updates.

> ⚠️  
> Use at your own risk. This is an open-source educational project.

---

## ✨ Features

| Feature                  | Description                                      |
|--------------------------|--------------------------------------------------|
| 📦 **Box ESP**           | Clean 2D/3D player boxes                         |
| 🏷️ **Name ESP**          | Player names with custom colors                  |
| ❤️ **Health Bar**        | Real-time health display                         |
| 📏 **Distance**          | Shows distance to players                        |
| 🦴 **Skeleton**          | Full skeleton rendering                          |
| 🌀 **Custom Settings**   | Adjust colors, size and transparency             |
| 🖥️ **Clean UI**          | Simple configuration panel                       |

---

## 🧩 How to use

1. Launch the tool.  
2. Configure your ESP settings.  
3. Join a Valorant match.  
4. Toggle the overlay on/off with the hotkey.

---

## ⚙️ Configuration

All settings can be changed in the config:

- Box style and color  
- Name display  
- Health bar  
- Distance  
- Skeleton  
- Hotkeys
